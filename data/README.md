# data · 源数据与初始化配置

本目录只放**课程模拟数据**，不包含真实患者信息。所有金额、床位、人力均为教学配置。

## 六份业务源数据

| 文件 | 行数 | 主要字段 | 用途 |
|---|---:|---|---|
| `mock_his/his_outpatient.csv` | 9,000 | 就诊号、患者、科室、日期、号别、费用 | 门诊量、次均费用、号别结构 |
| `mock_his/his_inpatient.csv` | 1,500 | 住院号、出入院日期、床号、病种、费用、药耗 | 出院、床日、住院日、药占比 |
| `mock_his/his_charge.csv` | 44,078 | 收费号、就诊号、费别、金额、日期 | 药品/耗材明细结构 |
| `mock_his/emr_record.csv` | 1,500 | 病历号、就诊号、诊断、病种 | 病历覆盖率、病种关联 |
| `mock_his/lis_report.csv` | 2,934 | 报告号、就诊号、项目、结果 | 检验异常率、检验覆盖率 |
| `files/finance_excel.csv` | 910 | 科室、日期、收入、药品、耗材 | 财务汇总与质量校验 |

时间范围：2025-04-01 至 2025-06-30。六源合计 59,922 行。

## 其他目录

- `init/`：科室、病种、费别、指标定义、质量规则与文件哈希清单，由 `scripts/export_init_data.py` 从代码常量生成。
- `supplemental_12m/`：12 个自然月的独立扩展模拟数据（236,028 行）与独立数仓，不进入默认主题。
- `derived/`：默认 SQLite、上传文件、覆盖率与测试报告，运行时生成，**不提交**。

## 隐私与使用边界

- `mock_his` 中的姓名、证件号、手机号为明显模拟值（`SIM-` 前缀），不是真实个人信息。
- DWD 使用加盐散列的 `patient_key`，但 ODS 的 `payload_json` 仍保留原始行内容，数据库与备份需按敏感文件管理。
- 不得将本目录数据替换为真实患者数据后公开或投入生产。

## 三个容易误解的数据事实

1. **各科室门诊人次都是 900**：源文件共 9,000 行，10 个科室各 900 条，是数据集按科室等量抽样的结果，不是平台补数。各科患者数 774—799、次均费用 403—439 元，月度分布也不同。
2. **住院收入有两套金额**：`his_inpatient.total_fee` 是结算账单，`his_charge.amount` 是收费明细。两者在模拟数据中不相等，K16—K25 使用账单口径，药品/耗材结构使用明细口径，页面均标注。
3. **床位有编制与开放两套口径**：编制床位 435 张（重症医学科 80 张），全院实际开放 345 张；科室使用率按编制计算，全院指标按开放计算。

这些口径差异不是数据错误，而是源数据设计；平台选择显式标注而不是强行对齐成一套数字。

# DESIGN.md — 医疗运营数据主题分析平台答辩

## 全局约定

- 画布 1280×720，上下左右安全边距 60px；页脚 y=670，14px。
- 场景：高校课程答辩，学术风；蓝白浅灰，主蓝 #1E4FA8，藏蓝 #0E3F8C，浅蓝 #E8EFF8，强调黄 #FFC107 仅作单一数据点，正文 #1A2230。
- 中文字体思源黑体；标题 36px Bold，卡片标题 24px Bold，正文 22px，注释 14px，KPI 72px。
- 视觉母题：页眉深蓝顶条 8px + 页脚左侧“医疗运营数据主题分析平台”，右侧页码。
- 无真实患者截图，不使用装饰性生成图；用结构图、表格、KPI 与真实平台数字表达证据。
- 统一四区：顶条 y0–8，标题 y44–124，内容 y140–650，页脚 y670。

## 反模式

- 禁止营销式“赋能/闭环/颠覆”等空话；禁止把模拟数据包装成真实医院成果。
- 禁止用截图占位图；截图由用户自行补充。
- 禁止每页堆卡片；数据页必须给判断，不只摆数字。

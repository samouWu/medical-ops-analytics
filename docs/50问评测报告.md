## 2. 评测定义

每题必须同时满足以下四项才算通过：

1. 识别出的指标编码与预期一致。
2. 科室识别与预期一致；全院问题不得误绑定科室。
3. 统计期起始日期与预期一致。
4. 指标能在当前数仓成功计算且结果非空。

评测只使用本地规则与统一指标服务，不调用 DeepSeek/Kimi，不依赖外部网络，因此结果可重复。题库覆盖30项当前有非空结果的指标（K25因无上年数据不纳入非空评测）、3个数据月份、全院及科室范围，并包含“本月”“上月”“最近30天”“2025-04”等不同问法。

## 3. 能力边界

本次通过的链路应准确称为 **受控语义指标问数**：

```text
自然语言
→ 指标/科室/时间语义识别
→ 白名单指标与参数化查询计划
→ DWS/DWD/ADS 数据计算
→ 图表和文字解读
```

它**不是**让大模型自由生成 SQL 后直接执行。外部 DeepSeek/Kimi 只负责对已经计算好的聚合事实生成简短解读，不接触患者明细，也不拥有数据库执行权限。

因此：

- 本报告证明当前 50 个课程评测问题达到 100% 准确率。
- 不证明任意开放域问题均可回答。
- 不证明模型生成 SQL 的安全性。默认指标问数不执行模型SQL；另有 `/ai/nl2sql` 受控接口，会先做表/列白名单与写操作拒绝，但真实模型Key生成尚未评测。
- 当前题库为项目内固定题库，不是第三方盲测集；后续应增加独立留出集和科室用户问法。

## 4. 复现命令

从项目根目录执行：

```bash
PYTHONPATH=backend .venv/bin/python -m etl.evaluation.run_eval
```

Windows Git Bash：

```bash
PYTHONPATH=backend .venv/Scripts/python.exe -m etl.evaluation.run_eval
```

自动回归测试还会执行同一题库，并要求准确率不低于 85%：

```bash
PYTHONPATH=backend .venv/Scripts/python.exe -m pytest backend/tests/test_ai_evaluation.py -q
```

# 运营看板截图目录

按项目约定，截图由用户自行完成并放入本目录。建议使用平台管理员账号登录后全屏截图，避免包含真实个人信息或密钥。

## 建议文件命名

| 文件名 | 页面 | 必拍内容 |
|---|---|---|
| `01-login.png` | 登录页 | 平台名称、账号输入框 |
| `02-dashboard.png` | 管理驾驶舱 | 5个核心指标卡、运营趋势、科室排行 |
| `03-dashboard-drilldown.png` | 驾驶舱下钻 | 下钻提示、返回全院按钮 |
| `04-outpatient.png` | 门诊分析 | 指标卡、趋势、科室分布、明细 |
| `05-inpatient-or-revenue.png` | 住院/收入分析 | 指标卡、趋势、构成 |
| `06-metrics-week.png` | 指标查询 | 指标口径、按周趋势 |
| `07-multidimensional-comparison.png` | 多维报表 | 同比/环比列、日期×科室结果 |
| `08-ai-answer.png` | 智能问数 | 问题、回答、图表、provider |
| `09-quality.png` | 数据质量 | 质量分数、10项规则 |
| `10-integration-or-audit.png` | 数据接入/审计 | 六任务、ADS回刷按钮或审计日志 |

## 截图要求

- 使用浏览器 1440px 以上宽度，保持文字可读。
- 不裁剪掉筛选条件、统计期或指标名。
- 不使用演示之外的真实患者数据。
- 不展示API Key、数据库连接串、令牌或个人敏感信息。
- 如页面显示 `local-rules`，这是无Key时的正常回退，不是错误。

## 归档说明

截图属于应用类成果物。完成拍摄后，将文件放入本目录，并在 `docs/验收报告.md` 的“运营看板截图”行把状态更新为“已提交”。

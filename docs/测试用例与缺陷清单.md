## 1. 测试范围与不在范围

范围内：

- 六源ETL、质量、幂等、隐私散列。
- 四层数仓、8主题DWS、公共时间维、ADS日/周/月与区间回刷。
- 指标目录、公式、日/周/月趋势、零分母、不可算指标。
- 登录、JWT、RBAC、科室隔离、审计。
- 驾驶舱、8主题、指标查询、多维报表、同环比、Excel/PDF、AI问数、报告、治理。
- 前端工具、图表配置、Lint和构建。
- 50问评测和自动门槛。

不在范围：

- 真实医院数据、官方DRG分组、生产LLM可用性。
- 百万并发、高可用、灾备、渗透测试。
- 容器实测和浏览器截图（截图由用户自行完成）。

## 4. 未执行与风险

1. 真实DeepSeek/Kimi API调用：未配置有效Key，仅验证回退、SQL校验和请求契约；模型生成SQL的真实效果未验证。

3. 浏览器E2E已完成14/14；Canvas柱形点击下钻、文件下载和截图仍需用户人工验收，截图由用户提交。
4. 并发冒烟已完成8并发120请求（P50 553.57ms、P95 2,282.46ms、错误率0%）；仍无容量梯度、长时间稳定性和生产SLA。
5. 深度安全专项：渗透、暴力登录限流、JWT密钥轮换、依赖漏洞扫描和恶意文件检测未执行。
6. 默认主题12个月接入、自由模型NL2SQL、自定义角色权限矩阵仍未完成；12个月独立附加库已完成验证，但未切入主题。

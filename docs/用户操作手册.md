# 用户操作手册

| 项目 | 内容 |
|---|---|
| 系统名称 | 医疗运营数据主题分析平台 |
| 版本 | V1.1 |
| 适用对象 | 管理员、运营分析师、科室负责人、演示观看者 |
| 更新日期 | 2026-11-20 |

## 1. 运行前准备

平台由前端和后端两个服务组成：

- 前端：http://127.0.0.1:5173
- 后端：http://127.0.0.1:8765
- API文档：http://127.0.0.1:8765/docs

首次运行需执行一次六源ETL，生成数仓与ADS结果。操作命令见 `README.md` 或 `docs/部署运维手册.md`。

## 2. 登录

1. 打开前端地址。
2. 输入用户名和密码。
3. 点击“登录”。

| 账号 | 密码 | 权限 |
|---|---|---|
| `admin` | `admin123` | 管理员 |
| `analyst` | `analyst123` | 全院分析 |
| `dept_hn` | `dept123` | 仅呼吸内科 HN |

说明：登录凭据属于演示账号，与当前 `backend/app/core/database.py` 初始化密码和测试账号一致。生产环境必须修改默认口令。

登录后左侧为主要导航，右上角显示当前用户及角色。令牌过期或被清除后，系统自动返回登录页。

## 3. 数据筛选

多数分析页面顶部有统一筛选条：

- 开始日期、结束日期：限定统计期。
- 科室：全院或授权科室。
- 重置：恢复数据完整日期范围并清空科室。
- 查询：应用筛选。

科室用户只能选择授权科室；即使手工修改URL参数，后端仍会返回403。

## 4. 管理驾驶舱

进入“运营总览 → 管理驾驶舱”。

主要区域：

1. 指标卡：门诊人次、出院人次、医疗总收入、床位使用率、药占比。
2. 运营趋势：按日展示门诊服务量和医疗收入，双轴图。
3. 科室收入排行：按收入降序显示前5科室。

### 下钻操作

1. 点击右侧“科室收入排行”的任一柱形。
2. 系统将该科室编码写入全局筛选并重新加载驾驶舱。
3. 页面顶部出现“当前已下钻至 XX科”提示。
4. 点击“返回全院”恢复。

## 5. 主题分析

左侧“主题分析”包含：

- 门诊分析
- 住院分析
- 收入分析
- 药品分析
- 耗材分析
- 病种分析
- 资源效率
- 患者服务

每个页面结构：

- 指标卡：核心指标汇总。
- 趋势图：按日显示主指标。
- 结构分布：科室、费别、病种或检验项目分布。
- 运营明细：分页表格。
- “导出报表”：下载当前主题的Excel。

### 主题下钻

在按科室分布的图表中，点击某个科室分类：

- 当前主题自动切换为该科室范围。
- 右上角出现“返回全院”。
- 页面上方显示下钻提示。

收入、药品、耗材等按费别/类别分布的图表，点击分类不会切换科室，因为分类不是科室维度。

## 6. 指标查询

进入“数据应用 → 指标查询”。

1. 在左侧目录搜索指标名称、编码或主题。
2. 点击某个可计算指标。
3. 右侧显示指标口径、单位和主题。
4. 选择“按日/按周/按月”。
5. 点击“查询”。
6. 查看汇总值、趋势图和分页明细。

灰色且标注“暂不支持”的指标缺源字段，不能查询。系统不会用0代替。

## 7. 多维报表

进入“数据应用 → 多维报表”。

操作：

1. 搜索并勾选最多8个指标。
2. 选择维度：科室、日期，可同时选择。
3. 选择时间粒度：日、周或月。
4. 勾选同比、环比（可只选一个或都不选）。
5. 点击“生成报表”。
6. 查看表格并点击“导出 Excel”。

说明：

- 同比为当前期间与上年同期比较；缺少上年数据时显示“—”。
- 环比为当前期间与上一相邻期间比较。
- 同时选择日期和科室时，表格会按每个科室内的时间序列展开。
- 只选科室时，一行代表一个科室的整段汇总。

## 8. 智能问数

进入“数据应用 → 智能问数”。页面提供两个模式：

- **指标问数**：把自然语言转换为受控指标查询，返回当前值和趋势图。
- **指标知识问答**：回答指标口径、权限、数据源、DWS/ADS、DRG、质量和模型隐私等问题，并返回来源提示。

示例问题：

- `2025年5月呼吸科门诊量是多少？`
- `本月出院人数`
- `上月床位使用率`
- `最近30天医疗总收入`
- `2025年6月药占比`

回答包含：

- 统计期和科室范围
- 指标名称和值
- 数据趋势图
- 供应商标识：`deepseek`、`kimi`、`local-rules` 或 `local-rules-fallback`

若未配置Key，使用本地规则解析与回答，这是正常回退；系统不会把本地规则伪装成模型调用成功。

### 提问限制

- 只支持聚合运营指标，不支持患者明细。
- 包含SQL写操作、身份证、手机号、患者姓名等内容会被拒绝。
- 管理员/分析师还可调用 `/api/v1/ai/nl2sql` 安全SQL接口：只允许单条SELECT聚合、白名单表、禁止患者标识和写操作，并使用只读连接执行。
- 安全SQL接口需要有效的DeepSeek/Kimi Key；未配置时返回503，不影响受控指标问数和知识问答。

## 9. 报告生成

进入“数据应用 → 报告生成”。

1. 选择周报或月报。
2. 选择基准日期。
3. 选择科室范围。
4. 点击生成。
5. 查看固定四章：总体概览、收入与结构、异常与归因、建议与口径。
6. “异常与归因”会显示相对上期的收入/门诊变化、5%/10%/35%阈值及科室贡献。
7. 每章下方显示指标、期间、来源表等口径证据。
8. 点击“打印/保存PDF”使用浏览器打印。
9. 也可调用后端PDF导出，生成真实PDF文件。

报告数值来自指标服务；异常归因是教学阈值和科室贡献提示，不构成管理决策或真实绩效结论。

## 10. 数据质量

进入“数据治理 → 数据质量”。

可查看：

- 最近质量分数。
- 质量规则通过/失败状态。
- 检查行数、失败行数、耗时。
- 最近ETL批次状态。

管理员/分析师可点击“运行质量规则”。规则失败不会自动修复数据，需要数据责任人处理。

## 11. 数据接入与任务

进入“数据治理 → 数据接入与任务”。

### 上传文件

1. 点击“导入数据文件”。
2. 选择CSV、XLSX或XLSM，最大20MB。
3. 系统自动识别模板并导入。
4. 查看成功行数和错误行原因。

支持模板：门诊、住院、收费、EMR、LIS、财务。字段不匹配会拒绝，不会猜测映射。

### 执行任务

任务列表显示六个日终任务及最近状态。点击“立即执行”只重跑对应源文件，并重建DWS/ADS。

### ADS回刷

点击“回刷ADS”：

- 系统重算全部日/周/月核心指标。
- 成功提示显示重算行数。
- 重复执行结果一致。

生产化环境中该操作应按影响评估安排窗口，避免与大批量ETL并发。

## 12. 审计日志

进入“数据治理 → 系统审计”。

管理员可查看登录、查询、导出、ETL、质量、AI等审计记录。审计包括时间、用户、动作、资源、详情和Trace ID。审计详情不应包含患者敏感原文。

## 12A. 系统管理

仅 `admin` 角色可见“系统管理”，其他角色直接访问路由会被重定向到驾驶舱。

页面分为四个标签：

1. **用户管理**：新增用户、修改显示名称/角色/科室范围、启用停用、重置密码、删除用户。系统禁止删除当前登录用户或最后一个启用的管理员。
2. **角色权限**：展示admin、analyst、department和预留engineer的职责与是否科室隔离。当前为固定系统角色，不支持自定义权限矩阵。
3. **数据源管理**：新增、编辑、启用停用、删除数据源；文件源可执行连接测试。数据库/API类型目前只保存配置，不提供采集。
4. **ETL任务管理**：新增、编辑调度表达式和重试次数、启用停用、删除、立即执行。调度表达式为课程元数据，生产级DAG和告警需外部调度系统。

所有新增、修改、删除和任务执行都会写审计。修改用户密码后，旧令牌在过期前仍可能有效，生产环境需增加令牌吊销或短时令牌机制。

## 13. 常见问题

| 现象 | 处理方法 |
|---|---|
| 页面无法连接数据服务 | 确认后端8765运行、Vite代理正常 |
| 登录提示用户名或口令错误 | 确认数据库初始账号与实际种子口令 |
| 图表无数据 | 执行ETL；确认筛选日期在数据范围2025-04-01至2025-06-30内 |
| 指标显示“暂不支持” | 该指标缺源字段，不是页面故障 |
| 导出无响应 | 检查登录状态、浏览器下载权限和后端日志 |
| AI显示local-rules-fallback | 未配置Key或外部调用失败，本地结果仍可用 |
| 科室用户403 | 请求了未授权科室，属正常权限控制 |
| 上传422 | 检查模板必填字段、日期格式、数值和主键冲突 |
| 上传413 | 文件超过20MB |

## 14. 数据与安全注意事项

- 仅用于课程模拟数据，不接入真实患者数据。
- ODS原始行可能包含身份字段，数据库和备份需按敏感文件保护。
- 不得共享演示账号、密钥或数据库文件。
- 不得将平台报告用于真实医院绩效、医保结算或临床决策。
- DRG/CMI、床位、人力为教学口径，不能对外作为正式结论。

## 文档维护约定

- 指标口径改动必须同步 `指标口径手册.md`、`需求规格说明书.md` 与 `data/init/metric_definition.csv`。
- 验收数字变化必须同步 `验收报告.md`、`测试计划与报告.md` 和 README 的状态表。
- 新增文档在本索引登记，避免出现“文件在、没人知道”的孤立文档。
- 文档中的数字以脚本输出为准，不手工调整测试结果。

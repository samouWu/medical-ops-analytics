## 1. 说明

## 2. 试运行范围

- 前端：管理驾驶舱、8主题、指标查询、多维报表、智能问数、报告、质量、数据接入、审计。
- 后端：登录、看板、主题、指标、多维、导出、问数、报告、质量、任务、血缘、用户、审计。
- 数据：六源59,922行、DWD宽表10,500行、8张主题DWS、ADS日/周/月36,828行。
- 环境：Python 3.13.14、Node 22、SQLite WAL、127.0.0.1:8765/5173。

## 4. 试运行发现

### 4.1 已修复

- 周/月ADS覆盖缺陷，已改为时间桶累加并重刷。
- 指标别名歧义，已改为长别名优先。
- 前端筛选与下钻状态不同步，已增加filters监听。
- 多维同环比、多维Excel、周查询在初版缺失，已补齐。
- 月报/主题导出文件签名与下载链路已验证。

### 4.2 仍需处理

1. 浏览器人工点击验收：登录、下钻、导出下载、页面错误态。
2. 真实Key下的LLM请求与超时回退。
3. Docker Compose、Nginx、卷持久化和恢复。
4. 确认是否将默认主题切换到12个月附加库；如切换需执行页面回归与全量对账。
5. 外部用户试运行、培训和反馈闭环。

## 5. 培训对象与目标

| 对象 | 培训目标 | 时长建议 |
|---|---|---:|
| 系统管理员 | 启动、账号、ETL、ADS回刷、质量、备份、排错 | 60分钟 |
| 运营分析师 | 驾驶舱、主题、指标、多维、同环比、导出、问数 | 45分钟 |
| 科室负责人 | 登录、科室筛选、科室看板、导出、权限边界 | 30分钟 |
| 验收教师 | 架构、数据链路、指标口径、测试证据、边界 | 30分钟 |

## 6. 培训内容

### 6.1 管理员

1. 环境变量与启动顺序。
2. 六源ETL与批次查看。
3. 质量规则执行和失败处理。
4. ADS全量/区间回刷。
5. 登录、导入、查询、导出审计。
6. 备份、恢复和回滚注意事项。

### 6.2 分析师

1. 统一筛选与日期范围。
2. 驾驶舱/主题指标解释。
3. 科室下钻和返回。
4. 指标日/周/月趋势。
5. 多维报表、同环比和Excel。
6. 智能问数的能力边界。
7. 报告生成和PDF。

### 6.3 科室负责人

1. 仅能查看授权科室。
2. 如何看科室指标和趋势。
3. 不可用数据与零分母的显示。
4. 导出和审计留痕。
5. 不得使用教学DRG/CMI作为绩效结论。

## 7. 培训考核建议

- 管理员：独立完成一次ETL、质量执行、ADS回刷和审计查询。
- 分析师：独立生成一份含同比/环比的多维Excel和一份月报。
- 科室用户：证明无法访问其他科室，能解释3个本科室指标。
- 验收教师：随机抽取指标复算并核对源数据。
